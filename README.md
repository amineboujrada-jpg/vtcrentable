# VTC Rentable

Site vitrine de l'appli VTC Rentable : https://vtcrentable.com

## Articles
Les pages `articles/` (index et articles) et `sitemap.xml` sont générées par `outils/articles.py` :
modifier le texte dans ce fichier puis lancer `python3 outils/articles.py`. Styles communs : `assets/article.css`.
